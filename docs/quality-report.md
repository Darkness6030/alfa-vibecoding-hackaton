# K8: Качество и большие тексты

Дата: 22.09.2026.

## Токенизатор

Заявленный токенизатор: `app/tokenizer.py` — разделение по пробелам/пунктуации (`\S+`). Это техническая единица учёта, не subword/LLM-токенизатор. TPS и требование 100 000 токенов измеряются по этому определению.

## Большие тексты (100 000 токенов)

Синтетический текст ~100 011 токенов (~713 КБ) с 27 вставками ПД (ФИО, email, телефон). Проверено:
- Точный round-trip: восстановление == исходник.
- Нет усечения: длина восстановленного == длина исходного.
- ПД на границах текста сохраняются.
- Время: mask ~0.42 с, restore ~0.01 с (локально).

## Качество (синтетический набор)

`benchmarks/quality_metrics.py`, 21 случай (17 позитивных + 4 негативных), точные span.

| Метрика | Значение |
| --- | --- |
| Precision | 1.00 |
| Recall | 1.00 |
| F1 | 1.00 |

Это локальная диагностика, не официальный evaluator. Набор синтетический и мал; реальная полнота на банковских текстах не измерена.

## Найденные и исправленные дефекты

1. **`resolve_spans` (критический):** проверка пересечения только против `accepted[-1]` ложно отбрасывала непересекающиеся span при сортировке по приоритету. Исправлено: проверка против всех принятых span.
2. **`mask` (критический):** сборка маскированного текста в порядке приоритета, а не по start, ломала round-trip при нескольких span. Исправлено: сортировка по start перед сборкой.
3. **Адрес банка (F01):** адрес отделения банка не должен быть ПД. Добавлен неперсональный контекст.
4. **Метрика качества:** использовала неразрешённые span (дубли PERSON/CARD_HOLDER); исправлено на `resolve_spans`.

## Ограничения

- Набор синтетический и мал; качество на реальных текстах не измерено.
- Токенизатор — техническая единица, не LLM-токенизатор.
- 100 000 токенов проверено на движке напрямую; через `/process` действует лимит `state_max_record_bytes` (1 МБ).
