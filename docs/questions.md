Насколько долго надо хранить состояние; какова максимальная пауза между парой и ретраями? Переиспользуются только тексты датасета или также id между прогонами? Может ли обратный шаг содержать изменённый LLM текст, а не точную копию маски? Предоставляется ли идентификатор прогона?

Все надо сделать максимально конфигурируемым, решение принять самостоятельно
